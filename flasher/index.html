Web Flasher

Flash your board over USB, straight from the browser — no esptool, no drivers.

This browser can't flash over USB. Use Chrome or Edge on desktop (Windows / Linux / macOS). Web Serial isn't available on Firefox, Safari, or phones. You need to open this page over https.

Before you click Install

  • Connect the board with a USB-C data cable and pick its serial port in the popup.
  • Updating a board that already runs BBoink? Leave Erase device unticked — your saved config (relay URL, keys, WiFi, settings) lives in a separate partition and is preserved. Only tick Erase device for a first install on a C5 board.
  • After flashing a C5 board (T-Display C5 / Waveshare), unplug and replug it to start the new firmware — the C5 doesn't auto-reboot after flashing.
  • Board not in the port list? Use a real data cable, and if needed force download mode: hold BOOT, tap RESET, release BOOT, then Connect.
